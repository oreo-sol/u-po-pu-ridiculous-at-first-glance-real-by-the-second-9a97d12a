One sentence, 200 characters at most, pitching a bizarre startup idea that
sounds absurd until you realise it would actually sell. Entry for the
[make.fun bounty](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a).

## The pitch

> We rent grandmothers to homesick students for Sunday dinner, because a stranger's grandma cooks like yours and costs less than therapy.

## How it runs

`main.ts` writes the pitch to `/output/entry.txt`:

```sh
node main.ts
```
